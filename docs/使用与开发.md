# 角色音频工坊 · Voice Workbench

一个本机运行的音视频处理桌面工具：粘贴视频链接或选择本地文件，导出原音 WAV，或分离人声后使用自选 RVC 模型转换角色音色，再合成为 WAV。

不依赖聊天机器人或云端变声服务。0.3.0 Windows 整合版自带处理与训练环境，解压后双击即可使用。音色可通过「导入音色」添加，也可直接用素材训练。

## 当前功能

- 视频链接、B 站分享文案与 BV 号；本地音视频文件导入。
- 原音导出与角色转换两种独立模式。
- 可选起止时间裁剪，输出 44.1 kHz、双声道、16 位 PCM WAV。
- 人声分离、RVC 变声、伴奏同步变调与混音。
- 串行任务队列、处理状态、取消、SQLite 历史记录、失败详情。
- 整合版自带 FFmpeg、Python、RVC、基础训练权重与 Demucs 人声分离模型；首次打开直接进入制作页，无需安装依赖或填写环境路径。自动选择 CUDA 或 CPU。
- 主界面「导入音色」将 .pth 与同目录的匹配 .index 复制到软件数据目录，不改变原文件；路径随整合包自动解析。
- 失败、中断或已完成的任务可「继续制作」，从上次停下的阶段往下跑；改音高、检索比例或伴奏比重不会重新分离人声。
- 试听原人声与转换结果（各约 12 秒），并可沿用上次任务的来源与参数再制作一版。
- 模型、索引、FFmpeg、外部 Python 和输出目录均可配置；分离缓存占用可见、可清理。
- 保留人声、伴奏、转换后人声、最终音频和处理记录；不覆盖源文件。
- 自动训练 RVC v2：批量导入音视频或文件夹，分离人声、筛选片段、提取音高和特征、训练并导出 `.pth` 模型与 `.index` 索引。
- 可调训练轮次、批次、采样率、学习率、检查点间隔及筛选强度；支持取消、筛选报告、素材试听及完成后选择使用新模型。

## Windows 使用

解压 Windows 发布包，双击 `VoiceWorkbench.exe`。

1. 下载名称含 `0.3.0-Portable` 的完整整合包，将整个文件夹解压到可写位置。请保留 EXE 旁的 `engine` 文件夹和 `portable.json`。
2. 双击 `VoiceWorkbench.exe`，添加本地文件或视频链接，直接选择「提取原音」开始制作。
3. 要换声时点「导入音色」选择自己的 `.pth`；匹配名称的 `.index` 或同目录唯一索引会自动一同导入。无需选择 Python、RVC 根目录或分离模型。
4. 没有音色模型时，可以切换「训练模型」，添加同一个人的素材，填写名称和轮次，直接训练。

基础环境和模型已随包提供，本地处理不需要联网安装。视频链接下载仍需要网络。建议 Windows 10/11 x64、16 GB 内存；可用 NVIDIA 显卡会自动加速，无可用 CUDA 时使用 CPU，耗时会增加。整合包较大，解压时请同时为压缩包、程序、音频任务及训练检查点留出空间。

主界面默认选择“提取原音”；点击“转换音色”切换至 RVC 流程。需要自定义名称或处理片段时，展开“命名与裁剪”。起点默认 0 秒，终点留空表示处理至结尾；收起选项仍保留已填参数。

默认原音模式不会应用角色转换、升调或音色滤镜。角色转换时，升调值作用于人声及伴奏；升调不是音色相似度的保证，效果取决于模型、输入和参数。

某些视频需要登录。软件不自动读取浏览器账号，可自行在设置中选择本地 Netscape 格式 Cookie 文件。解析失败会保留明确失败状态；也可先下载视频再用本地导入。不同网站的链接可用性会变化，以实际测试为准。

## 自动训练自己的音色

切换顶部“训练模型”，添加同一个人的音视频文件或素材文件夹，填写模型名称、训练轮次和批次大小，点击“开始训练”。软件会依次提取音轨、分离人声、去除静音和不合格片段、提取音高及音色特征、训练 RVC v2，最后生成模型和检索索引。无需先准备角色权重，整合版已内置训练环境和 32k/40k/48k 的基础预训练权重。

“更多参数”包含：

- 采样率：32k、40k、48k，默认 40k。
- 学习率、检查点保存间隔、均衡或严格素材筛选。
- 是否自动分离人声：视频及含伴奏素材建议开启；已经清理好的干声可关闭。
- 是否保留训练检查点：默认成功导出后清理本任务的 G/D 检查点，保留最终模型、索引、筛选后的人声和报告。勾选后额外保留检查点；当前不提供应用内续训操作。

轮次默认 200、批次默认 4，均可修改。显存不足时先减小批次；增加轮次不保证效果更好。训练与音频制作共用串行队列，可在任务记录里查看进度、取消及失败原因。双击完成的训练任务可查看筛选结果、打开人声素材并试听；选中任务后点击“使用此模型”，才会把新模型应用到音频制作。

建议至少准备累计 10 分钟清晰、音色一致的人声，参考 [RVC 官方材料建议](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI/blob/main/docs/en/README.en.md)。软件要求筛选后至少 30 秒有效人声才允许开始训练，这是流程的最低门槛，不是质量标准。素材越杂、原声越模糊，越难训练出稳定音色。

自动处理识别的是可用的人声片段，并通过音量、削波、音高比例及人声相对伴奏的强弱筛选；不识别人物身份，也不自动把多人对白分成不同角色。分离不能保证完全没有伴奏、和声或混响，请尽量提供同一个人的独唱或独白，并检查保留片段。此功能训练的是音频驱动的 RVC 变声模型，不是输入文字即可说话的 TTS 模型。

训练当前适配具有 `train/`、`assets/hubert_base/`（Transformers HuBERT）、`assets/rmvpe/rmvpe.pt` 和 `assets/pretrained_v2/f0G*.pth`、`f0D*.pth` 的 RVC 环境。缺少文件时会显示具体路径；传统 HuBERT 布局仍可用于音色转换，但训练适配尚未覆盖。训练需要额外磁盘空间，长素材和保留检查点会增加占用；至少预留 2 GB，小规模以外建议更多。

## 从源码运行

建议 Python 3.12，系统 Python 需带 Tkinter：

```sh
python -m pip install -r requirements.txt
python main.py
```

命令行也可使用：

```sh
python cli.py "https://www.bilibili.com/video/视频BV号" --mode original
python cli.py "local-video.mp4" --mode convert --start 30 --end 60 --name "片段"
python cli.py "voice-materials" --mode train --name "我的音色" --epochs 200 --batch-size 4
python cli.py --resume "输出/20261024_183000_ab12cd34ef56"
```

`--resume` 指向任务文件夹：已完成的阶段（下载、提取、分离、转换、混音）按指纹复用，只重跑失效的部分。桌面端选中失败或中断的任务点“继续制作”等价于它。

命令行和桌面端默认共用当前用户的软件设置。测试时可用环境变量 `VOICE_WORKBENCH_HOME` 指向独立数据目录。

## RVC 引擎与模型

整合版的角色转换和训练工作进程在包内的独立 Python 中运行。当前适配 [RVC-Project WebUI](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI) 的 `VC`、RMVPE 与训练接口；分离默认使用随包提供的 [Demucs](https://github.com/facebookresearch/demucs)。源码模式仍可手动连接已有的兼容 RVC 环境，并支持旧版 BS-RoFormer 分离适配器。

当前适配器识别传统 `assets/hubert/hubert_base.pt` 和新版 `assets/hubert_base` 布局。缺少引擎依赖会明确报错。中文路径的索引通过内存加载。

0.3.0 整合包包含独立 Python、FFmpeg、RVC 推理/训练代码及依赖、HuBERT/ContentVec、RMVPE、RVC 基础权重、Demucs 基础分离模型与许可证。包内不含开发者的角色权重、音频素材、Cookie 或账号配置。程序自己的代码为 MIT 许可；随包的第三方组件及模型保留各自许可，详见 `THIRD_PARTY_NOTICES.md` 与 `licenses/`。

## 开发与打包

```sh
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
python build_windows.py
```

真实音频测试会查找 PATH 中的 FFmpeg，也可设置 `VOICE_TEST_FFMPEG` 指向其完整路径。Windows 包须在 Windows 上构建。`build_windows.py` 只生成界面 EXE；完整免配置交付还需运行：

```sh
python build_portable.py --engine "兼容RVC根目录" --destination "dist/VoiceWorkbench-0.3.0-Portable" --frontend "dist/VoiceWorkbench.exe"
```

该脚本只复制白名单基础资产，排除角色权重、检索库、历史、素材和设置，并准备内置分离器。构建需要网络，最终用户运行本地任务无需下载依赖。不能只把界面 EXE 当作整合版发布。

## 本地数据与发布

整合版的设置、导入音色、历史及默认成品保存在程序目录的 `data/` 中；源码/旧版模式仍默认位于 `%LOCALAPPDATA%/VoiceWorkbench`。输出目录可另选。测试可通过 `VOICE_WORKBENCH_HOME` 指向独立目录。公开分享请使用干净的发布 ZIP，不要把个人使用后的 `data/` 一并打包。

发布源码前排除模型、音频、Cookie、运行参数、用户数据、开发依赖及私有开发笔记；项目已提供 `.gitignore`。可以公开程序源码，不代表可以一并公开任意下载素材或角色权重。
