# RVC-Tomorin · 角色音频工坊

一个在 Windows 本机运行的音频工具：粘贴视频链接或导入本地文件，就能导出 WAV、分离人声、转换音色，也能训练自己的 RVC 音色。不依赖 QQ 或云端变声服务。

## 下载使用

**[下载 Windows 安装助手](https://github.com/Sunba666/RVC-Tomorin/releases/latest/download/RVC-Tomorin-Setup.exe)** · [查看全部发行文件](https://github.com/Sunba666/RVC-Tomorin/releases/latest)

1. 下载并双击 `RVC-Tomorin-Setup.exe`。
2. 助手会自动下载、校验并解压完整环境，完成后打开软件。无需安装 Python、RVC 或填写环境路径。
3. 添加视频链接或本地文件，选择「提取原音」开始制作；需要换声时，点「导入音色」选择自己的 `.pth` 模型。

首次下载约 **6 GB**，请预留 **20 GB** 空间。支持下载中断后继续。安装后可从桌面快捷方式打开，也可再次运行安装助手直接启动。

建议使用 **Windows 10/11 64 位、16 GB 内存**。可用 NVIDIA 显卡会自动加速，没有可用 CUDA 时使用 CPU，速度会慢一些。本地处理可以离线，视频链接下载需要联网；链接能否下载取决于站点和访问权限。

> 请下载上面的安装助手。GitHub 的「Code → Download ZIP」是程序源码。

## 可以做什么

- 视频链接、本地音视频 → WAV，可裁剪起止时间。
- 分离人声和伴奏，使用 RVC 模型转换音色并混音。
- 试听、任务历史、取消、失败后继续制作。
- 自动训练音色，可调整轮次、批次和采样率，导出 `.pth` 与 `.index`。

## 训练自己的音色

打开「训练模型」→ 添加同一个人的素材 → 填写名称和轮次 → 开始训练。完成后选择任务，点击「使用此模型」。

建议准备至少 10 分钟清晰、同一人的独唱或独白。软件会分离和筛选人声，但不会自动区分不同人物，也无法保证完全去掉和声或混响。这里训练的是 RVC 变声模型，不是文字转语音模型。

音色模型由使用者导入或训练。公开仓库与发行包不包含私人角色权重、素材、Cookie 或账号配置。

## 开发者

建议 Python 3.12，在仓库根目录运行：

```sh
python -m pip install -r requirements.txt
python main.py
```

源码模式需要连接兼容的 RVC 环境；普通使用者下载上方免配置发行版即可。详细使用、源码运行与打包说明见 [使用与开发](docs/使用与开发.md)，验证范围见 [TESTING.md](TESTING.md)。
